# Ritrovo (lost_found)

Prototipo del sito di oggetti smarriti per il Ticino e la zona di confine (Como, Varese, Verbano).
Pagina statica unica (`index.html`) con scena 3D (three.js, GSAP, Lenis: tutto in `assets/js`, niente CDN), dati di esempio e nessun collegamento alle fonti reali.

Pubblicazione: GitHub Pages dal branch `main`, cartella radice.
